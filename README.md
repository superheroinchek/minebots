# Minebots

Мини-проект демонстрирует лёгкий агент с последовательностью «обдумывание →
формулировка» и маленьким веб-интерфейсом.

## Запуск веб-сервера

```bash
python -m minebots.web --host 0.0.0.0 --port 8000
```

Флаги необязательны и позволяют указать адрес и порт. После запуска откройте
<http://127.0.0.1:8000> в браузере. Страница содержит
форму ввода, отображение хода рассуждений и финального ответа, а также историю
диалога.

## Тесты

```bash
pytest
```

Тесты проверяют корректность инструментов и базовый сценарий работы веб-сервера.
