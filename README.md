# Minebot

Minebot — это Python-проект, реализующий Minecraft-бота с когнитивной архитектурой на базе LLaMA 11B.

## Возможности

- Подключение к серверу Minecraft через библиотеку [pyCraft](https://github.com/ammaraskar/pyCraft)
- Цикл восприятия → планирование → действие при помощи большой языковой модели
- Библиотека атомарных действий (движение, добыча блоков, размещение, крафт, атака)
- Планировщик задач на графах и подсистема памяти (краткосрочная и долговременная)
- CLI на Typer для генерации конфигураций и запуска бота

## Требования

- Python 3.10+
- Установленная модель LLaMA 11B в формате Hugging Face (директория с весами и токенизатором)
- Запущенный сервер Minecraft Java Edition. Для полноценного крафта и боя удобно иметь серверные плагины, обрабатывающие команды `/craft` и `/attack`.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -e .
```

## Настройка

1. Сгенерируйте шаблон конфига:
   ```bash
   minebot init-config --path minebot.yml
   ```
2. Укажите путь к весам LLaMA 11B (`llama.model_path`), а при необходимости токенизатор и устройство.
3. Настройте параметры подключения к серверу Minecraft.

## Запуск

```bash
minebot start --config-path minebot.yml --goal "Построить укрытие до наступления ночи"
```

Бот будет циклически собирать наблюдения, генерировать планы через LLaMA и выполнять действия на сервере.

## Структура проекта

```
src/minebot/
├── actions.py          # Реестр действий и обработчики
├── cli.py              # CLI на Typer
├── config.py           # Работа с конфигурацией
├── llama_agent.py      # Интеграция LLaMA 11B
├── logging_config.py   # Настройки логирования
├── memory.py           # Подсистема памяти
├── minecraft_bot.py    # Основной цикл бота
├── minecraft_client.py # Клиент для сервера Minecraft (pyCraft)
└── planner.py          # Планировщик задач
```

## Тестирование

Минимальная проверка — импорт пакета и запуск CLI помощи:

```bash
python -m minebot.cli --help
```

Для полноценного тестирования потребуется сервер Minecraft и загруженные веса модели.
